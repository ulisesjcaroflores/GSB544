# GSB 544: Computing and Machine Learning for Analysis

Coursework for GSB 544 (Cal Poly MSBA).

| Folder | What it holds |
|---|---|
| `Labs/` | one folder per lab (`Lab1` ... `Lab8`), each with the notebook and, where available, the rendered HTML |
| `Comprehensive_Assessment/Classification/` | take-home final (Kaggle classification) and its dashboard |
| `Comprehensive_Assessment/Regression/` | take-home final (Kaggle regression) and its dashboard |

Notes
* Each dashboard (`.qmd`) runs its notebook with `%run`, so the `.qmd` and the `.ipynb` sit in the same folder.
* Data files are not stored here; notebooks read them from the paths set in their first cells.
